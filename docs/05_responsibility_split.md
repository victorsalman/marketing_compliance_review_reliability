# Responsibility Split

## Language model

Interpret context, negation, quotation, sarcasm, measurable claims, superiority claims, competitor criticism, customer attribution, genuine semantic uncertainty, and evidence span selection.

## Deterministic software

Perform RULE_1 lexical scanning, JSON parsing, schema enforcement, allowed value validation, exact substring verification, duplicate handling, deterministic rule mapping, final outcome calculation, and rejection or retry of malformed output.

## Human review

Resolve genuine ambiguity, review claims requiring business or compliance judgment, assess external supporting evidence, make policy decisions that are not fully encoded, and handle cases rejected by automated validation when repair is unsafe.
