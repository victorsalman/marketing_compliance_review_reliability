# Architecture

The candidate uses one semantic model call surrounded by deterministic processing.

1. Preserve the original marketing copy.
2. Deterministic software scans only the frozen RULE_1 prohibited vocabulary.
3. One language model interprets semantic rules and returns rule identifiers, issue states, exact source evidence, and concise explanations.
4. Deterministic software validates JSON, schema, allowed values, exact source substring evidence, duplicates, and RULE_1 candidate eligibility.
5. Deterministic software maps rules and issue states to APPROVED, REVIEW, or REJECTED.
6. Human review handles unresolved ambiguity and claims requiring business or compliance judgment.

The language model does not calculate the final business outcome.
