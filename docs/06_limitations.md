# Limitations

The examples were synthetic.

The model was tested conversationally rather than through independent API executions.

The development set had 31 submissions and the unseen holdout had 10 submissions.

There was no production traffic, real customer data, external compliance evidence channel, latency measurement, cost measurement, retry measurement, throughput measurement, privacy assessment, operational monitoring, or deployment.

The experiment does not establish production accuracy, production readiness, security guarantees, or externally validated compliance performance.

Prompt injection behavior was tested only in controlled source text examples and should not be treated as a security proof.
