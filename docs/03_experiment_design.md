# Experiment Design

Development Benchmark V1 contained 31 synthetic English marketing submissions. Expected answers were frozen before execution. The run occurred in the same Veteran Prompt Engineering AI conversation that had previously discussed the benchmark, so it is described as a controlled same conversation development test rather than an unseen benchmark.

After development, a new 10 submission synthetic holdout was created outside that Veteran AI chat. The new submissions and expected answers were not supplied to the Veteran AI before execution.

The experiment scored semantic issue sets, issue states, evidence selections, final deterministic outcomes, false approvals, and raw JSON validity separately.
